# Mercia Zaayman – Portfolio

A one-page portfolio site, hosted with GitHub Pages. Plain HTML and CSS: no build step.

## Hosting

GitHub Pages: repo **Settings → Pages → Deploy from a branch → `main` / root**. Optional custom domain such as `portfolio.zaayman.co.nz` (add a CNAME DNS record pointing to `mercia-coder.github.io`).
